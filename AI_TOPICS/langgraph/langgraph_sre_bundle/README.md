
# LangGraph SRE Bundle

This is a starter project for an enterprise SRE agent.

## Install

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Create `.env` with:

```
OPENAI_API_KEY=your_key
```

Run:

```bash
python main.py
```
